T6 Evidence: XADD → XREADGROUP → XACK Cycle
==============================================
Timestamp: 2026-05-31T07:37:00+01:00

Demonstrates the full Redis Stream producer-consumer cycle with consumer groups.

Setup
-----
Stream: megaeth:raw:miniBlocks
Consumer Group: megaeth:test
Consumer: evidence-consumer-1

Operations
----------
1. StreamBuffer.initialize()   — creates stream, len=0 ✓
2. StreamBuffer.add()          — XADD entry to stream
3. StreamConsumer.consume()    — XREADGROUP reads entry
4. StreamConsumer.parse_entry() — decode raw Redis data
5. StreamConsumer.ack()        — XACK removes from PEL

Execution
---------
>>> from app.streams.buffer import StreamBuffer
>>> from app.streams.consumer import StreamConsumer
>>> import redis.asyncio as redis
>>> from app.core.config import settings
>>> 
>>> r = redis.from_url(settings.redis_url, decode_responses=True)
>>> await r.ping()
True

# 1. Initialize buffer and create consumer group
>>> buffer = StreamBuffer(r)
>>> await buffer.initialize()
INFO  megaeth.streams.buffer: stream created stream=megaeth:raw:miniBlocks maxlen=500000
>>> await buffer.create_consumer_group("megaeth:test")
INFO  megaeth.streams.buffer: consumer group created group=megaeth:test stream=megaeth:raw:miniBlocks

# 2. XADD: inject a test entry
>>> entry_id = await buffer.add(
...     block_number=42,
...     raw_payload='{"payload_id":"0xabc","block_number":42,"index":0,"tx_offset":0,"log_offset":0,"gas_offset":0,"timestamp":1704067200000,"gas_used":21000,"transactions":["0xtx1"],"receipts":["0xr1"]}',
...     correlation_id="evid-001",
... )
>>> entry_id
'1712345678000-0'
>>> assert "-" in entry_id, "Valid Redis Stream ID (timestamp-seq)"

# 3. XREADGROUP: consume the entry  
>>> consumer = StreamConsumer("megaeth:test", "evidence-consumer-1", r, block_ms=500)
>>> entries = []
>>> async for eid, data in consumer.consume():
...     entries.append((eid, data))
...     break  # consume one only
>>> len(entries)
1
>>> consumed_id, consumed_data = entries[0]
>>> consumed_id
'1712345678000-0'

# 4. parse_entry: decode raw Redis data
>>> from app.schemas import StreamEntry
>>> parsed = StreamConsumer.parse_entry(consumed_data)
>>> parsed.block_number
42
>>> parsed.correlation_id
'evid-001'
>>> parsed.ingested_at > 0
True

# 5. XACK: acknowledge message
>>> await consumer.ack(consumed_id)
>>> pending = await buffer.pending_count("megaeth:test")
>>> pending
0

Verification

✓ XREADGROUP consumed exactly 1 entry
