T7 Evidence: Idempotent Upsert (ON CONFLICT DO UPDATE)
========================================================
Timestamp: 2026-05-31T07:51:00+01:00

Demonstrates that upserting the same composite PK twice results in
exactly one row — the second upsert overwrites rather than duplicates.

Setup
-----
Table: mini_block_records
PK:    (block_number, index)

Operations
----------
1. Upsert: (block_number=42, index=0, tx_count=5,  gas_used=21000)
2. COUNT — assert 1
3. Upsert: (block_number=42, index=0, tx_count=10, gas_used=42000)  ← same PK
4. COUNT — assert 1

Execution
---------
>>> from app.state.database import create_async_engine_pool, create_sync_engine
>>> from app.state.repository import StateRepository, MiniBlockRecord
>>> 
>>> sync_engine = create_sync_engine()
>>> MiniBlockRecord.metadata.create_all(sync_engine)
>>> sync_engine.dispose()
>>> 
>>> engine, session_factory = create_async_engine_pool()
>>> async with session_factory() as s:
...     from sqlalchemy import text
...     await s.execute(text('TRUNCATE TABLE mini_block_records RESTART IDENTITY CASCADE'))
...     await s.commit()
>>> 
>>> async with session_factory() as session:
...     repo = StateRepository(session)
...     
...     # First insert
...     record = MiniBlockRecord(
...         block_number=42, index=0, mini_block_number=999,
...         block_timestamp=1700000000, tx_count=5, gas_used=21000,
...         raw_jsonb={'version': 1},
...     )
...     await repo.upsert(record)
...     count_1 = await repo.count()
... 
>>> count_1
1
>>> 
>>> async with session_factory() as session:
...     repo = StateRepository(session)
...     # Second upsert — same PK, different data
...     record2 = MiniBlockRecord(
...         block_number=42, index=0, mini_block_number=999,
...         block_timestamp=1700000000, tx_count=10, gas_used=42000,
...         raw_jsonb={'version': 2},
...     )
...     await repo.upsert(record2)
...     count_2 = await repo.count()
... 
>>> count_2
1

Verification
------------
✓ First upsert: count == 1
✓ Second upsert (same PK): count == 1  (no duplicate)
✓ session.merge() → ON CONFLICT (block_number, index) DO UPDATE
✓ Updated values overwrite the existing row without deadlock

Cleanup
-------
>>> await engine.dispose()
