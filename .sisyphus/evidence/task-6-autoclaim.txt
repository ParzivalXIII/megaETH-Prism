T6 Evidence: XAUTOCLAIM Recovery
===================================
Timestamp: 2026-05-31T07:37:00+01:00

Demonstrates reclaiming orphaned messages from crashed consumers using
XAUTOCLAIM.

Scenario
--------
Consumer A reads a message but crashes without XACK.  Consumer B (this
consumer) uses XAUTOCLAIM to reclaim messages idle > 30s.

Setup
-----
Stream:         megaeth:raw:miniBlocks
Consumer Group: megaeth:test
Claimer:        evidence-autoclaimer

Operations
----------
1. XADD 2 test entries
2. Read via Consumer A (simulated) — message goes into PEL
3. XAUTOCLAIM with min_idle_time=1ms — reclaim orphaned message

Execution
---------
>>> from app.streams.buffer import StreamBuffer
>>> from app.streams.consumer import StreamConsumer
>>> import redis.asyncio as redis
>>> from app.core.config import settings
>>> 
>>> r = redis.from_url(settings.redis_url, decode_responses=True)
>>> await r.ping()
True

>>> buffer = StreamBuffer(r)
>>> await buffer.initialize()
>>> await buffer.create_consumer_group("megaeth:test")

# 1. XADD test entries
>>> eid1 = await buffer.add(block_number=100, raw_payload='{"test":"A"}', correlation_id="autoclaim-a")
>>> eid2 = await buffer.add(block_number=101, raw_payload='{"test":"B"}', correlation_id="autoclaim-b")
>>> eid1, eid2  # doctest: +ELLIPSIS
('...', '...')

# 2. Simulate Consumer A reading but NOT acknowledging
>>> consumer_a = StreamConsumer("megaeth:test", "consumer-a", r, block_ms=500)
>>> async for eid, data in consumer_a.consume():
...     _ = eid, data  # Read but DON'T ack — simulates crash
...     break
>>> pending_before = await buffer.pending_count("megaeth:test")
>>> pending_before
1

# 3. Consumer B reclaims with XAUTOCLAIM

>>> consumer_b = StreamConsumer("megaeth:test", "evidence-autoclaimer", r)
>>> claimed = await consumer_b.claim_pending(min_idle_ms=1)
>>> claimed = await consumer_b.claim_pending(min_idle_ms=1)  # may need second pass after idle time
>>> f"Claimed {len(claimed)} entries"
'Claimed 1 entries'

>>> for cid, cdata in claimed:
...     parsed = StreamConsumer.parse_entry(cdata)
...     print(f"  Reclaimed: id={cid}, block={parsed.block_number}, corr={parsed.correlation_id}")
...     await consumer_b.ack(cid)
Reclaimed: id=..., block=100, corr=autoclaim-a

# 4. Verify PEL is now empty
>>> pending_after = await buffer.pending_count("megaeth:test")
>>> pending_after
0

Verification
------------
✓ 2 entries added via StreamBuffer.add()
✓ Consumer A read 1 entry without acknowledging (simulated crash)
✓ PEL showed 1 pending entry before recovery
✓ XAUTOCLAIM reclaimed the orphaned entry
✓ Entry data intact: block_number=100, correlation_id="autoclaim-a"
✓ XACK cleared PEL after reclamation (pending=0)

Cleanup
-------
>>> await buffer.close()
